# Design and workflow reference

Source: supplied PRD and owner-provided design and process-flow screenshots.

Primary #166534, hover #14532D, background #F8FAFC, surface white, text #111827, muted #475569, border #CBD5E1, focus #2563EB. System sans, 16px body, 14px labels, headings 20/24/32px. Spacing 4/8/12/16/24/32/48px, controls 8px radius, cards 12px. Minimum target 44px. Always show keyboard focus, labels and text explanations for status.

Desktop sidebar at 1024px. Mobile bottom navigation Home/Create/Library/More; Planner and Invoices reachable inside More. Current preview navigation will be aligned as the corresponding routes are introduced.

First promotion: register → verify email → business and owner membership → business profile → product with photo and confirmed facts → goal/channel/tone brief → quota confirmation → durable job producing three variations → review/edit/approve exact version → graphic preview/download and caption copy → manual sharing → optional quotation or invoice.

Weekly planner: select one to five products → choose Lagos start date and goal → confirm three-unit cost → durable generation → seven distinct dated unapproved items → review each → export → owner marks done.

Sale: select product or approved content → customer → editable draft and totals → preview → idempotent issue with immutable snapshots → private PDF → manual sharing → owner-entered payments and supported reversals.

Failures preserve input. Pending jobs stay discoverable. Failed generations release reservations. Copy/download is never publication evidence. Financial mutations require explicit confirmation. Issued records never change when catalogue details change.
